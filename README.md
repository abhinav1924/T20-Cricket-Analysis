# 🏏 Cricket World Cup Player Performance Dashboard

An end-to-end data analytics project that showcases player performance in the ICC T20 World Cup using a custom-built Power BI dashboard.

## 🚀 Purpose

To analyze and visualize player stats based on their roles (Openers, Anchors, Finishers, All-Rounders, Bowlers) and help users build a performance-based "Final 11" team.

## 🔧 Tech Stack

- **Python (Pandas)** – Data cleaning & preprocessing  
- **Web Scraping** – Collected player stats from cricket websites  
- **Power BI** – Built the interactive dashboard with DAX for metrics

## 📈 Outcome

- Role-wise player comparison using key metrics like Strike Rate, Average, Economy, Dot Ball %, etc.
- Interactive visuals with filters for combined and individual player insights
- Final 11 selection panel based on performance data
